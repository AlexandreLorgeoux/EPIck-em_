Symbole Oracup et icône d'application. Le symbole se pose seul ; le nom se compose à côté en texte (Archivo, `font-stretch: 125%`, poids 800).

- `oracup-mark.svg` : traits `ink` (#11201f) et point jaune cerclé d'encre, pour fond clair. Encre unique : une balise `<img>` ne peut pas hériter d'une couleur.
- `oracup-mark-dark.svg` : traits #eef5f2 et point jaune sans cercle, pour fond sombre.
- `oracup-app-icon.svg` : carré arrondi `brand` (#0c5c57), symbole clair, pour l'icône mobile et le favicon.

Taille minimale : symbole 24px. Zone de protection : un diamètre du point jaune.
