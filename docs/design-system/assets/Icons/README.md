Quatre icônes de statut, grille de 24px, trait de 2px, extrémités et jointures arrondies. Chacune accompagne un mot.

- `icon-check.svg` : Juste, vainqueur, choix confirmé.
- `icon-close.svg` : Faux, erreur.
- `icon-lock.svg` : Verrouillé.
- `icon-live.svg` : En direct.

Encre unique #11201f : une balise `<img>` ne peut pas hériter d'une couleur. Dans une interface, intègre le SVG en ligne avec `stroke="currentColor"` pour suivre le thème.
